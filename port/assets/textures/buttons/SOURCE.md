# Input Viewer texture sources

The PNG layers in this directory are copied from Ship of Harkinian 9.2.3:

`soh/assets/custom/textures/buttons/`

Upstream project: <https://github.com/HarbourMasters/Shipwright>

They are kept as separate, composited layers so G-Diffuser's Input Viewer matches SoH's N64
controller overlay rather than approximating it with ImGui primitives.
